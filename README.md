## Sobre mí

Estudio **Ingeniería Informática, mención Desarrollo de Software**, en **Duoc UC**, con egreso previsto para **2027**.

Me interesa desarrollar soluciones que combinen **software, infraestructura cloud y aplicaciones de inteligencia artificial**. En mis proyectos académicos y personales he trabajado con **Java, Spring Boot, Python, React, Docker, Linux y AWS**, poniendo especial atención en el aprendizaje práctico, la arquitectura y la seguridad.

Actualmente me preparo para realizar mi **práctica profesional a partir de julio/agosto de 2027**, con interés en equipos de **IA aplicada, Cloud/DevOps o Ingeniería de Software**.

## Proyectos seleccionados

### [PokePeluche — Fullstack + AWS](https://github.com/JuanBeltranV/tienda-pokepeluche)

Proyecto académico de catálogo y administración de productos, desarrollado con **React y Spring Boot**.

- Autenticación con **Amazon Cognito** y autorización por roles (**USER, EDITOR y ADMIN**) mediante **Spring Security** y JWT.
- **API REST**, persistencia con **SQLite**, formularios y administración de productos.
- Integración demostrativa con **AWS API Gateway** y pruebas con **JUnit, MockMvc y Vitest**.

**Tecnologías:** React · Java · Spring Boot · AWS Cognito · API Gateway · SQLite

[**Ver código y documentación →**](https://github.com/JuanBeltranV/tienda-pokepeluche)

### [Country Clash — React + APIs](https://github.com/JuanBeltranV/country-clash)

Juego web interactivo para comparar la población de distintos países, con mapas y siluetas geográficas.

- Interfaz **responsive** desarrollada con **React y Vite**.
- Uso de **D3 Geo, TopoJSON y datos geográficos** para representar países.
- Publicación mediante **GitHub Pages**.

**Tecnologías:** React · JavaScript · Vite · D3 Geo · TopoJSON

[**Probar demo →**](https://juanbeltranv.github.io/country-clash/) · [**Ver repositorio →**](https://github.com/JuanBeltranV/country-clash)
